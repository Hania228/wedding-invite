## Website Description
This website is created to provide information about an event. Visitors can explore the event details, view the schedule of activities and submit their RSVP responses. The website has a simple and attractive design with easy navigation.

## Website Pages
1. **Home Page (index.html):** Displays the main information and details about the event.
2. **Schedule Page (schedule.html):** Shows the event schedule and planned activities.
3. **RSVP Page (rsp.html):** Allows visitors to respond to the event invitation.
